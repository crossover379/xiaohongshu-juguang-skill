# 聚光AI投手·小红书广告智能优化助手 v4.3.0 ⚡

## 「智能投手」— 主动提议定时自动化

v4.3 的核心升级：AI 投手不只帮你做一次，而是**主动提议把重复劳动变成定时任务**。

> **核心理念**：每次完成操作后，必须问一句「要不要设个定时，以后自动帮你做？」

## 🆕 v4.3 亮点

- 🚀 **首次安装引导**：装完立刻引导绑定聚光账户，主动提供回调地址，小白不用自己搜文档
- ⚡ **8 种定时任务**：每日数据早报 / 智能日报 / 每周创意筛查 / 每周僵尸清理 / 异常预警 / 预算预警 / 周报 / 月报
- 🤖 **结尾必提定时**：每次操作结束，AI 自动匹配 1-2 个推荐的定时任务并主动提议
- 🔗 **一键开通**：用户说「全部定时」→ 5 个核心任务一键配好
- 🎯 **精准提议**：看完数据 → 提议数据早报；做完筛查 → 提议每周筛查；发现异常 → 提议预警

## v4.2 亮点

- 🧠 **主动式对话**：筛查完创意 → 追问转化目标 → 定制方案 → 帮执行
- 🎯 **4 轮智能对话**：目标追问 → 定制方案 → 主动帮执行 → 闭环总结
- 📊 **目标×策略对照表**：4 种转化目标 × 不同行动策略

## 🆕 v4.1 亮点

- 🔬 **创意筛查**：6维评分 × 行业基准 × 趋势检测 × 问题诊断 → 明确的投/不投决策
- 🩺 **差创意自动诊断**：6种常见问题自动检测并给修复方案

## v4.0 亮点

- 🤖 **对话式交互**：每次回复包含 数据 → 解读 → 建议 三层
- 📊 **行业基准值**：5 大行业 × 5 个指标
- 🎓 **5 轮新手引导**：自然对话式
- 🩺 **业务诊断**：「为什么没转化」→ 四维排查
- ✅ **前置检查**：操作前自动检查

## 安装

1. 将本 Skill 解压到 `~/.workbuddy/skills/xiaohongshu-juguang-ai/`
2. 编辑 `xiaohongshu_config.json`，填入你的聚光平台凭证
3. 重启 WorkBuddy

## 配置

编辑 `xiaohongshu_config.json`：

```json
{
  "app_id": "你的AppID",
  "app_secret": "你的AppSecret",
  "advertiser_id": "你的广告主ID"
}
```

### 获取凭证

1. 打开聚光平台：https://ad.xiaohongshu.com
2. 进入「应用管理」创建应用
3. 获取 AppID 和 AppSecret

## 使用方式

**直接对话即可！** 试试这些：

- 「看看今天数据」「大盘怎么样」
- 「生成昨天的日报」
- 「分析一下我的计划」
- 「帮我投一个酒店广告，日预算 200」
- 「哪个创意表现最好？」
- 「清理僵尸计划」
- 「怎么投放？」（新手引导）
- 「为什么我的广告没有咨询？」（业务诊断）

## 注意事项

1. **操作前确认**：所有增/删/改操作都会先展示预览，等你确认后才执行
2. **金额单位**：API 返回的金额是「分」，AI 会自动转成「元」展示
3. **数据时效**：离线报表 T+1 上午 10 点出数，实时报表 5-10 分钟延迟
4. **批量限制**：批量操作单次上限 20 个 ID
